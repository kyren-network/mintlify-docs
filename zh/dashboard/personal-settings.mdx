使用个人设置管理你自己的控制台账户和安全设置。

## 常见任务

| 任务 | 说明 |
| --- | --- |
| 个人资料 | 保持联系信息最新。 |
| 密码 | 使用强密码，并在团队权限变更时及时更新。 |
| 双重验证 | 启用 2FA，保护敏感操作。 |
| 账户安全 | 在重新生成 API 密钥或修改结款账户信息前，先检查安全设置。 |

## 安全提醒

- 不要分享密码或 2FA 验证码。
- 不要通过聊天或普通邮件发送 API 密钥、Webhook Secret 或身份证件，除非 Kyren Pay 明确要求使用安全渠道。
- 移除不再需要控制台访问权限的团队成员。
