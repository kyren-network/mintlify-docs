使用个人设置管理你自己的控制台账户和安全设置。

## 常见任务

| 任务 | 说明 |
| --- | --- |
| 个人资料 | 保持联系信息最新。 |
| 密码 | 使用强密码，并在团队权限变更时及时更新。 |
| 双重验证 | 启用 2FA，保护敏感操作。 |
| 账户安全 | 在重新生成 API 密钥或修改结款账户信息前，先检查安全设置。 |

## 设置 2FA

使用双重验证（2FA）为你的控制台账户增加一次性验证码校验。

1. 登录启润支付商户控制台。
2. 在控制台导航中打开**个人设置**。
3. 找到**双重验证**，点击**启用 2FA**。
4. 使用 Google Authenticator、Microsoft Authenticator、1Password 等验证器应用扫描二维码。
5. 输入验证器应用中的 6 位验证码，完成绑定确认。
6. 如果页面提供恢复码，请把恢复码保存在安全位置。

启用 2FA 后，登录或执行敏感账户操作时可能需要输入验证器应用中的验证码。如果你无法访问验证器应用或恢复码，请通过已验证的账户渠道联系 Kyren 支持。

## 安全提醒

- 不要分享密码或 2FA 验证码。
- 不要通过聊天或普通邮件发送 API 密钥、Webhook Secret 或身份证件，除非 Kyren Pay 明确要求使用安全渠道。
- 移除不再需要控制台访问权限的团队成员。
