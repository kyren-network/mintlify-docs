使用订单页面查看付款状态、查找订单标识，并将 Kyren Pay 记录与你自己的系统对账。

## 需要检查的字段

| 字段 | 用法 |
| --- | --- |
| 订单号 | 咨询 Kyren 支持时提供该信息。 |
| 状态 | 判断你的系统应该履约还是继续等待。 |
| 金额和币种 | 与产品或 Checkout Session 金额核对。 |
| 创建和支付时间 | 与你的服务端日志核对。API 中的时间使用毫秒级时间戳。 |
| 支付渠道 | 识别客户使用的支付方式。 |

## 对账流程

1. 在控制台搜索订单。
2. 将状态、金额、币种和时间戳与你的内部记录核对。
3. 检查你的 Webhook 端点是否收到对应事件。
4. 如果系统需要自动对账，使用 Orders API。

## 退款

对于已支付或已结款订单，已启用退款权限的商户可以从订单详情页提交退款申请。对账退款订单时，请同时查看退款申请状态、退款记录状态和 `order.refunded` Webhook 事件。

## 金额与手续费分担

订单金额是原始商品金额，应付金额包含客户承担的手续费。分别查看商户和客户承担的费率、每笔固定手续费及 USD 费用金额。每笔固定手续费以 USD 配置。[支付方式](/zh/dashboard/payment-methods)中的配置修改不会重写已有订单的费用快照。

应付金额不等于商户净收入。请结合费用分担、保证金、汇率及实际 USD 结算金额，与[资金](/zh/dashboard/funds)对账。已关闭和支付失败订单隐藏费用详情；费用或结算金额为空不能证明已收到款项。

## 争议订单

订单存在争议敞口或已记录拒付影响时，可能显示 `DISPUTED` 或 `CHARGEBACK`。在[争议案件](/zh/dashboard/disputes)中查看关联案件、截止时间及实际冻结或扣除金额。案件状态与已完成的资金操作可能不同，请核对资金记录，不要仅凭案件状态判断资金已释放。
