提交 KYC 或 KYB 时需要接受 Merchant Services Agreement。历史商户也可能在控制台收到补签提醒。阅读公开协议页面或加载最新正文不会记录接受行为。

## 在认证提交时签署

1. 在 [KYC](/zh/dashboard/kyc) 或 [KYB](/zh/dashboard/kyb) 中填写所需资料并提交。
2. 查看协议弹窗中的签署主体、法定名称、授权签署人及注册邮箱。个人 KYC 提交也可能使用账户已有的企业主体，请以弹窗实际展示的主体为准。
3. 阅读协议版本和生效日期，确认由展示的签署人本人操作，并有权代表商户接受协议。
4. 在正文底部勾选同意，再点击**同意协议并提交认证**。
5. 核对认证提交结果及审核状态。

如果当前版本和同一主体已有有效接受记录，弹窗会展示并允许复用该记录。主体或正文发生变化时，需要阅读并确认更新后的协议。展示信息不正确时，点击**返回修改资料**。

接受记录与展示的版本、正文和签署主体绑定。Kyren 在后端保留接受证据并生成签署 PDF。需要协助查询签署记录时请联系支持；该流程没有控制台 PDF 下载按钮。

签署协议不代表 KYC 或 KYB 审核通过，认证仍需单独审核。

## 补签提醒与宽限期

收到提醒后，点击**立即签署**，阅读当前协议、勾选同意并提交。成功后检查提醒是否消失。正文已更新时，弹窗会重新加载并要求再次阅读确认。

宽限期截止时间按香港时间显示。在门禁适用时，超过截止时间仍未签署的商户不能新建 Checkout 或易支付付款、生成或重新生成 API Key，也不能启用已绑定的支付方式。已有订单及退款处理、争议查询、余额、结款申请和结款账户仍可访问，同时仍受各自账户及认证条件限制。

未签署也可能在适用要求下阻止待审核认证获批。补签会保留既有认证材料和申请状态，使审核可以继续。

协议或签署主体加载失败时，使用重新加载操作。如果接受失败、主体不正确，或成功提交后提醒仍在，请向 Kyren 支持提供商户 ID、展示的版本、操作时间和错误信息。
