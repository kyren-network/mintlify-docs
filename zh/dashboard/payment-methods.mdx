在商户控制台打开**支付方式**，查看账户已经绑定的支付方式、状态和订单手续费分担。需要开通列表中没有的支付方式时，请联系 Kyren 支持。

## 启用或禁用

1. 找到支付方式并查看当前状态。
2. 使用操作栏的开关启用或禁用。
3. 等待成功提示，再在新的 Checkout 中检查可用方式。

绑定已启用仍受平台可用性、渠道配置、币种和账户限制影响。渠道不可用，或适用的[商户服务协议](/zh/dashboard/merchant-agreement)补签要求已逾期时，启用可能失败。禁用支付方式不会取消已支付订单或撤销其资金。

## 设置手续费分担

点击支付方式对应的**设置手续费承担方式**。弹窗显示订单总费率和每笔固定手续费，并支持填写：

| 设置 | 含义 |
| --- | --- |
| 客户承担费率 | 用于计算 Checkout 附加费用的客户费率分担。控制台输入百分比；`customerFeeRate` 使用十进制费率，例如 `0.01` 表示 1%。 |
| 客户承担每笔固定手续费 | 客户每笔承担的固定部分，以 USD 配置，对应 `customerPerTransactionFee`。 |
| 商户承担部分 | 分别按总费率、总固定手续费减去客户承担部分自动计算。 |
| Checkout 展示文案 | 可选的 Checkout 描述，最多 80 个字符。 |

客户承担的两项均不能为负，也不能超过对应的订单总手续费。两项均设为零表示手续费全部由商户承担。点击**保存**后，先用新的 Checkout 核对，再交付客户。

原始订单金额是商品价格；应付金额会加上客户承担的手续费，商户净收入则反映商户承担部分及适用保证金。固定手续费始终以 **USD** 配置，即使订单使用其他币种。对账时查看[订单](/zh/dashboard/orders)中的应付金额、费用分担、换汇及结算金额。修改配置不会重写已有订单的费用快照。

Checkout 会计入附加费用本身产生的处理费：`（原始金额 × 客户费率 + 换算为订单币种的客户固定费）÷（1 − 订单总费率）`，结果四舍五入至两位小数。例如原始金额 USD 100.00、总费率 3%、客户承担 1% 加 USD 0.20，附加费用为 USD 1.24，应付金额为 USD 101.24。实际扣款以 Checkout 报价和订单记录为准。

## 同一支付方式有多个渠道

支付方式名称不能唯一标识渠道；同一种方式可能绑定不同 Provider 或接入路由。完整渠道身份包括 Provider、Provider 支付方式代码、接入模式和业务模式。

当前控制台按支付方式发起操作，尚未提供完整的路由选择控件。如果出现重复方式，或保存提示需要渠道身份，请联系 Kyren 支持确认目标绑定，并提供支付方式、目标 Provider 和错误信息。不要假定一个开关会更新所有路由。
