`/epay/api.php` 提供 Epay 兼容的运维动作。使用 `act=order` 查询迁移后的 Epay 风格订单。`act=refund` 当前不支持，会返回兼容错误；退款需通过平台协助另行处理。

## 订单查询

调用 `GET` 或 `POST` `/epay/api.php?act=order`，传入 `pid`、原始商户 `key`，以及 `out_trade_no` 或 `trade_no` 之一。

该端点为了兼容订单查询，使用原始商户 `key` 和 `pid`。开启 API IP 白名单时可能会校验来源 IP。

```bash
curl "https://api.kyren.top/epay/api.php?act=order&pid=10001&key=merchant_secret&out_trade_no=ORDER_10002"
```

成功响应示例：

```json
{
  "code": 1,
  "msg": "查询订单号成功！",
  "trade_no": "K202605260001",
  "out_trade_no": "ORDER_10002",
  "type": "alipay",
  "pid": "10001",
  "addtime": "2026-05-26 10:30:00",
  "endtime": "2026-05-26 10:31:12",
  "name": "AI credits",
  "money": "9.99",
  "status": 1,
  "param": "account_123",
  "buyer": ""
}
```

`addtime` 和 `endtime` 在该兼容查询暴露时是 Epay 兼容的日期时间字符串。

失败响应示例：

```json
{
  "code": 0,
  "msg": "order not found"
}
```

## 退款兼容

`GET` 或 `POST` `/epay/api.php?act=refund` 当前不支持，会返回兼容错误。不要基于此路径构建自动退款逻辑。请与 Kyren 平台协助单独协调退款处理。

响应示例：

```json
{
  "code": 0,
  "msg": "refund compatibility endpoint is currently unsupported"
}
```

查看 [`api.php` API 参考](/api-reference/epay-compatibility/apiphp-order-queryrefund-compatibility-endpoint)。
