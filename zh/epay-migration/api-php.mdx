`/epay/api.php` 提供 Epay 兼容的运维动作。使用 `act=order` 查询迁移后的 Epay 风格订单。使用 `act=refund` 为符合条件的 Epay 来源订单提交退款。

## 订单查询

调用 `GET` 或 `POST` `/epay/api.php?act=order`，传入 `pid`、原始商户 `key`，以及 `out_trade_no` 或 `trade_no` 之一。

该端点为了兼容订单查询，使用原始商户 `key` 和 `pid`。开启 API IP 白名单时可能会校验来源 IP。

```bash
curl "https://api.kyrenpay.com/epay/api.php?act=order&pid=10001&key=merchant_secret&out_trade_no=ORDER_10002"
```

成功响应示例：

```json
{
  "code": 1,
  "msg": "查询订单号成功！",
  "trade_no": "K202605260001",
  "out_trade_no": "ORDER_10002",
  "type": "alipay",
  "pid": "10001",
  "addtime": "2026-05-26 10:30:00",
  "endtime": "2026-05-26 10:31:12",
  "name": "AI credits",
  "money": "9.99",
  "status": 1,
  "param": "account_123",
  "buyer": ""
}
```

`addtime` 和 `endtime` 在该兼容查询暴露时是 Epay 兼容的日期时间字符串。

失败响应示例：

```json
{
  "code": 0,
  "msg": "order not found"
}
```

## 退款兼容

调用 `GET` 或 `POST` `/epay/api.php?act=refund`，传入 `pid`、原始商户 `key`、`money`，以及 `out_trade_no` 或 `trade_no` 之一。

该路径只用于通过 Epay 兼容端点创建的订单。原生 Kyren API 订单应使用原生退款 API。商户账户必须已开通退款权限，且订单仍有足够的可退金额。

可选的 `refund_no` 用于幂等。如果不传，Kyren 会使用订单 ID 和标准化后的退款金额生成兼容幂等键。

```bash
curl "https://api.kyrenpay.com/epay/api.php?act=refund&pid=10001&key=merchant_secret&trade_no=K202605260001&money=9.99&refund_no=REFUND_10002"
```

响应示例：

```json
{
  "code": 1,
  "msg": "退款提交成功",
  "trade_no": "K202605260001",
  "out_trade_no": "ORDER_10002",
  "refund_no": "REFUND_10002",
  "refund_id": "refund_abc123",
  "money": "9.99",
  "status": "PROCESSING"
}
```

查看 [`api.php` API 参考](/api-reference/epay-compatibility/apiphp-order-queryrefund-compatibility-endpoint)。
