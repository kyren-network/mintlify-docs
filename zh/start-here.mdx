## 推荐路径

1. 创建或检查商户账户。
2. 创建一个产品。
3. 创建 Checkout Session 或 Checkout 链接。
4. 完成一次付款流程。
5. 配置并验证 Webhook。
6. 确认你的系统能正确履约。
7. 检查上线清单。
