`/epay/api.php` 提供 Epay 相容的維運動作。使用 `act=order` 查詢遷移後的 Epay 風格訂單。使用 `act=refund` 為符合條件的 Epay 來源訂單提交退款。

## 訂單查詢

呼叫 `GET` 或 `POST` `/epay/api.php?act=order`，傳入 `pid`、原始商戶 `key`，以及 `out_trade_no` 或 `trade_no` 之一。

該端點為了相容訂單查詢，使用原始商戶 `key` 和 `pid`。開啟 API IP 白名單時可能會驗證來源 IP。

```bash
curl "https://api.kyrenpay.com/epay/api.php?act=order&pid=10001&key=merchant_secret&out_trade_no=ORDER_10002"
```

成功回應範例：

```json
{
  "code": 1,
  "msg": "查询订单号成功！",
  "trade_no": "K202605260001",
  "out_trade_no": "ORDER_10002",
  "type": "alipay",
  "pid": "10001",
  "addtime": "2026-05-26 10:30:00",
  "endtime": "2026-05-26 10:31:12",
  "name": "AI credits",
  "money": "9.99",
  "status": 1,
  "param": "account_123",
  "buyer": ""
}
```

`addtime` 和 `endtime` 在該相容查詢暴露時是 Epay 相容的日期時間字串。

失敗回應範例：

```json
{
  "code": 0,
  "msg": "order not found"
}
```

## 退款相容

呼叫 `GET` 或 `POST` `/epay/api.php?act=refund`，傳入 `pid`、原始商戶 `key`、`money`，以及 `out_trade_no` 或 `trade_no` 之一。

該路徑只用於透過 Epay 相容端點建立的訂單。原生 Kyren API 訂單應使用原生退款 API。商戶帳戶必須已開通退款權限，且訂單仍有足夠的可退金額。

可選的 `refund_no` 用於冪等。如果不傳，Kyren 會使用訂單 ID 和標準化後的退款金額產生相容冪等鍵。

```bash
curl "https://api.kyrenpay.com/epay/api.php?act=refund&pid=10001&key=merchant_secret&trade_no=K202605260001&money=9.99&refund_no=REFUND_10002"
```

回應範例：

```json
{
  "code": 1,
  "msg": "退款提交成功",
  "trade_no": "K202605260001",
  "out_trade_no": "ORDER_10002",
  "refund_no": "REFUND_10002",
  "refund_id": "refund_abc123",
  "money": "9.99",
  "status": "PROCESSING"
}
```
