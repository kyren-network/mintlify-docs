在商戶控制台的**爭議案件**中查看已匹配到自己訂單的案件。案件可用性及資金處理取決於平台和 Provider 是否已為帳戶及環境啟用。清單為空不能證明 Provider 側沒有爭議。

## 查看案件

1. 開啟**爭議案件**，按需使用狀態篩選和分頁尋找案件。
2. 核對 Provider 案件號、訂單 ID、案件類型、金額、狀態和發生時間。
3. 點擊**查看詳情**開啟詳情抽屜。
4. 查看原因、回應截止時間、資金影響和案件時間線。
5. 需要回應時，及時聯絡 Kyren 支援並提供案件號和訂單 ID。

清單及詳情抽屜均為唯讀。提交證據、申訴、修改案件和執行資金操作需要與營運支援協調。**待回應**狀態或截止時間不代表系統已自動提交回應。時間線只展示允許商戶查看的事件。

## 案件狀態與資金

| 項目 | 核對內容 |
| --- | --- |
| 案件狀態 | 是否待回應、已提交抗辯材料，或已勝訴、敗訴、接受、取消、關閉。 |
| Provider 爭議金額 | Provider 報告的案件金額和幣種，可能不同於結算幣種。 |
| 實際凍結本金 | 已記錄為凍結的本金。 |
| 關聯滾動準備金 | 與案件關聯的準備金。 |
| 已扣本金、已抵扣滾動準備金 | 已記錄扣除或用於抵扣拒付的金額。 |
| 拒付費 | 按展示的結算幣種記錄的拒付費用。 |

活動爭議可能凍結受影響資金；符合條件的釋放可以返還凍結資金；拒付則扣除受影響本金，並可能抵扣關聯準備金及產生拒付費。這些操作取決於資金處理是否啟用以及記錄的結果。僅憑案件終態不能確認資金操作已經完成，也不能認為已拒付資金已經恢復。

同一訂單存在多個關聯案件時，詳情會提示共享的訂單資金上下文。不要將共享金額逐案相加當作獨立餘額。請結合[資金](/zh-Hant/dashboard/funds)、交易流水和[訂單](/zh-Hant/dashboard/orders)核對實際金額。

## 通知與支援

爭議通知啟用時，`dispute.created` 和 `dispute.updated` 可以通知你的端點案件變化，詳見 [Webhook 事件](/zh-Hant/webhooks/events)。透過案件識別碼關聯通知，再查詢最新案件及資金記錄；案件通知本身不能證明餘額操作成功。

案件缺失、即將到期，或資金與案件狀態不一致時，請向支援提供商戶 ID、Provider 案件號、訂單 ID、金額、幣種、截止時間和相關時間戳。不要提供 API Key 或 Webhook Secret。
