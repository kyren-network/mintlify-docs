使用個人設定管理你自己的控制台帳戶和安全設定。

## 常見任務

| 任務 | 說明 |
| --- | --- |
| 個人資料 | 保持聯絡資訊最新。 |
| 密碼 | 使用強密碼，並在團隊權限變更時及時更新。 |
| 雙重驗證 | 啟用 2FA，保護敏感操作。 |
| 帳戶安全 | 在重新產生 API 密鑰或修改結款帳戶資訊前，先檢查安全設定。 |

## 設定 2FA

使用雙重驗證（2FA）為你的控制台帳戶增加一次性驗證碼校驗。

1. 登入啟潤支付商戶控制台。
2. 在控制台導覽中開啟**個人設定**。
3. 找到**雙重驗證**，點擊**啟用 2FA**。
4. 使用 Google Authenticator、Microsoft Authenticator、1Password 等驗證器應用程式掃描 QR code。
5. 輸入驗證器應用程式中的 6 位驗證碼，完成綁定確認。
6. 如果頁面提供恢復碼，請把恢復碼保存在安全位置。

啟用 2FA 後，登入或執行敏感帳戶操作時可能需要輸入驗證器應用程式中的驗證碼。如果你無法存取驗證器應用程式或恢復碼，請透過已驗證的帳戶渠道聯絡 Kyren 支援。

## 安全提醒

- 不要分享密碼或 2FA 驗證碼。
- 不要透過聊天或普通郵件傳送 API 密鑰、Webhook Secret 或身份證件，除非 Kyren Pay 明確要求使用安全渠道。
- 移除不再需要控制台存取權限的團隊成員。
