使用商戶控制台管理付款設定、產品、Checkout、訂單、餘額、KYC 和開發者設定。

## 主要區域

| 區域 | 用途 |
| --- | --- |
| 產品 | 建立和管理你銷售的內容。 |
| 訂單 | 查看付款、訂單狀態和對帳資訊。 |
| 餘額 | 查看餘額和結款相關記錄。 |
| KYC | 在結款需要時提交必要的驗證資料。 |
| 開發者 | 管理 API 密鑰、Webhook 設定和整合配置。 |
| 設定 | 管理商戶資料、網站、Logo、預設幣種、安全設定和可用時的 IP 白名單。 |

## 建議首次設定

1. 檢查商戶資料和網站資訊。
2. 建立產品。
3. 透過 API 建立 Checkout Session，或產生 Checkout 流程。
4. 在開發者設定中配置 Webhook。
5. 在訂單中查看已支付訂單。
