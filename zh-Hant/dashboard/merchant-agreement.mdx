提交 KYC 或 KYB 時需要接受 Merchant Services Agreement。歷史商戶也可能在控制台收到補簽提醒。閱讀公開協議頁面或載入最新正文不會記錄接受行為。

## 在認證提交時簽署

1. 在 [KYC](/zh-Hant/dashboard/kyc) 或 [KYB](/zh-Hant/dashboard/kyb) 中填寫所需資料並提交。
2. 查看協議彈窗中的簽署主體、法定名稱、授權簽署人及註冊信箱。個人 KYC 提交也可能使用帳戶已有的企業主體，請以彈窗實際展示的主體為準。
3. 閱讀協議版本和生效日期，確認由展示的簽署人本人操作，並有權代表商戶接受協議。
4. 在正文底部勾選同意，再點擊**同意協議並提交認證**。
5. 核對認證提交結果及審核狀態。

如果目前版本和同一主體已有有效接受記錄，彈窗會展示並允許複用該記錄。主體或正文發生變化時，需要閱讀並確認更新後的協議。展示資訊不正確時，點擊**返回修改資料**。

接受記錄與展示的版本、正文和簽署主體綁定。Kyren 在後端保留接受證據並產生簽署 PDF。需要協助查詢簽署記錄時請聯絡支援；該流程沒有控制台 PDF 下載按鈕。

簽署協議不代表 KYC 或 KYB 審核通過，認證仍需單獨審核。

## 補簽提醒與寬限期

收到提醒後，點擊**立即簽署**，閱讀目前協議、勾選同意並提交。成功後檢查提醒是否消失。正文已更新時，彈窗會重新載入並要求再次閱讀確認。

寬限期截止時間按香港時間顯示。在門禁適用時，超過截止時間仍未簽署的商戶不能新建 Checkout 或易支付付款、產生或重新產生 API Key，也不能啟用已綁定的支付方式。已有訂單及退款處理、爭議查詢、餘額、結款申請和結款帳戶仍可存取，同時仍受各自帳戶及認證條件限制。

未簽署也可能在適用要求下阻止待審核認證獲批。補簽會保留既有認證材料和申請狀態，使審核可以繼續。

協議或簽署主體載入失敗時，使用重新載入操作。如果接受失敗、主體不正確，或成功提交後提醒仍在，請向 Kyren 支援提供商戶 ID、展示的版本、操作時間和錯誤資訊。
