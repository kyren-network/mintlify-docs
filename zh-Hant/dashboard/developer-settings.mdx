使用開發者設定把你的服務端接入 Kyren Pay。

## API 密鑰

API 密鑰只能在服務端使用。不要把密鑰暴露在前端 JavaScript、行動端應用、日誌、截圖或公開倉庫中。

如果重新產生 API 密鑰，需要更新所有呼叫 Kyren Pay 的服務端環境。舊密鑰會在重新產生後失效。

## Webhook

配置一個 Kyren Pay 可以透過 HTTPS 存取的 Webhook URL。你的服務端應在信任事件內容前驗證 Webhook 簽名。

## IP 白名單

如果你的商戶帳戶啟用了 IP 白名單，確保所有呼叫 Kyren Pay 的伺服器 IP 都已加入。缺少伺服器 IP 可能導致認證或授權失敗。
