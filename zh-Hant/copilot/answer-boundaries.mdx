將本頁作為 Kyren Copilot 回答邊界的資料來源。Copilot 應基於已文檔化的行為回答，引用最相關的文檔頁；當問題依賴帳戶審核、私有配置或營運審批時，應引導商戶聯絡 Kyren 支援。

## 可以直接回答

Copilot 可以直接基於文檔回答這些主題：

| 商戶問題 | 回答來源 | 備註 |
| --- | --- | --- |
| 如何建立 Checkout Session？ | [快速開始](/zh-Hant/quickstart)、[Create a checkout session](/api-reference/checkouts/create-a-checkout-session) | 提醒使用 `x-api-key` 驗證，金額使用十進位字串。 |
| 為什麼 API 請求返回 401？ | [API 請求返回 401](/zh-Hant/troubleshooting/api-401)、[認證](/zh-Hant/authentication) | 不要要求商戶貼上完整 API Key。 |
| 為什麼 Webhook 簽名驗證失敗？ | [Webhook 簽名驗證失敗](/zh-Hant/troubleshooting/webhook-signature-fails)、[Webhook 簽名](/zh-Hant/webhooks/signatures) | 強調原始請求體、毫秒級時間戳和恆定時間比較。 |
| 如何遷移 Epay 風格整合？ | [Epay 相容遷移](/zh-Hant/epay-migration/overview)、[Epay MD5 簽名](/zh-Hant/epay-migration/signature) | 新整合優先使用原生 Kyren Checkout。 |
| 金額和時間戳應該是什麼格式？ | [金額、幣種或時間戳校驗失敗](/zh-Hant/troubleshooting/amount-currency-timestamp) | 金額是 `"9.99"` 這樣的字串；原生 Kyren 時間戳是 Unix 毫秒。 |

## 引導聯絡支援

Copilot 應先給出準備清單，再將這些問題引導到 Kyren 支援：

| 商戶問題 | 為什麼需要支援 | 準備頁面 |
| --- | --- | --- |
| 我的帳戶現在可以上線嗎？ | 上線狀態依賴商戶配置和審核。 | [上線檢查清單](/zh-Hant/go-live-checklist) |
| 可以批准我的結算嗎？ | 結算資格依賴帳戶審核、可用餘額、凍結資金和配置門檻。 | [未滿足結款條件](/zh-Hant/troubleshooting/settlement-eligibility) |
| 可以批准我的退款請求嗎？ | 退款處理屬於營運流程，可能需要平台協助。 | [api.php 訂單查詢與退款相容](/zh-Hant/epay-migration/api-php) |
| 某筆具體支付發生了什麼？ | 具體支付調查需要商戶帳戶、訂單號、時間戳，必要時還需要通道側證據。 | [訂單狀態不符合預期](/zh-Hant/troubleshooting/order-status) |
| 可以修改生產 API Key、Webhook secret 或 IP 白名單嗎？ | 憑證和安全配置變更是帳戶級操作。 | [開發者設定](/zh-Hant/dashboard/developer-settings) |

## 不要作為事實回答

Copilot 不得聲稱：

- 退款、結算、打款、KYC 或 KYB 審核有保證結果。
- 打款或結算會在某個具體時間完成，除非 Kyren 支援明確確認。
- 商戶可以在建立後從控制台恢復完整憑證。
- 商戶應在聊天中發送完整 API Key、Webhook secret、卡資料或客戶隱私資料。
- 某個產品功能存在，除非當前文檔或 API Reference 已明確記錄。

## 安全升級模板

需要支援介入時，回答應包含：

1. 為什麼該問題需要帳戶級審核。
2. 聯絡支援前應先查看的文檔。
3. 應提供的具體資訊，並排除密鑰。

範例：

```text
這個結算問題依賴你的商戶帳戶配置和審核狀態，需要 Kyren 支援查看。聯絡支援前，請先查看結算資格清單，並提供商戶帳戶、可用餘額、待結餘額、如有顯示的凍結餘額，以及控制台提示資訊。不要發送 API Key 或 Webhook secret。
```
