啟潤支付使用標準 HTTP 狀態碼來表示 API 請求的成功或失敗。

## HTTP 狀態碼

| 狀態碼 | 描述 |
| --- | --- |
| `200` | 成功 — 請求已成功處理 |
| `201` | 已建立 — 資源建立成功 |
| `400` | 錯誤請求 — 參數無效 |
| `401` | 未認證 — 缺少或無效的 API 密鑰 |
| `403` | 禁止存取 — 權限不足 |
| `404` | 未找到 — 資源不存在 |
| `409` | 衝突 — 資源狀態或冪等衝突 |
| `429` | 請求過多 — 超出頻率限制 |
| `500` | 伺服器內部錯誤 — 我們這邊出了問題 |
| `503` | 服務不可用 — 上游服務錯誤 |

## 錯誤回應格式

由 API 應用層處理的錯誤使用以下 JSON 結構。認證中介軟體和代理錯誤的回應本體可能為空或採用其他格式，請先檢查 HTTP 狀態再解析 JSON。

```json
{
  "code": 40001,
  "message": "Validation failed",
  "error": {
    "field": "productId",
    "reason": "Product ID is required"
  }
}
```

| 欄位 | 類型 | 描述 |
| --- | --- | --- |
| `code` | integer | 應用錯誤碼，與 HTTP 狀態碼不同 |
| `message` | string | 人類可讀的錯誤訊息 |
| `error.field` | string | 導致錯誤的參數（如適用） |
| `error.reason` | string | 詳細的錯誤說明 |

<Note>
  `error` 是可選欄位，有欄位詳情時才包含。`field` 和 `reason` 也可能分別省略。不要依賴錯誤訊息的固定文字。
</Note>

## 應用錯誤碼

| 錯誤碼 | 含義 |
| --- | --- |
| `40001` | 請求無效或驗證失敗 |
| `40101` | 應用層未認證錯誤 |
| `40102` | Token 已過期 |
| `40103` | API 密鑰無效 |
| `40301` | 禁止存取 |
| `40401` | 資源不存在 |
| `40901` | 衝突 |
| `40902` | 冪等衝突 |
| `42901` | 超出頻率限制 |
| `50001` | 伺服器內部錯誤 |
| `50002` | 外部服務錯誤（HTTP `503`） |
| `60006` | 產品不存在 |
| `60007` | Checkout 已過期 |
| `60008` | 訂單不存在 |

這些錯誤碼表示錯誤條件。業務錯誤可能使用 HTTP `400`，不要根據 `code` 的前幾位推斷 HTTP 狀態。

## 常見錯誤

### 400 錯誤請求

請求本體或參數無效時返回。

```json
{
  "code": 40001,
  "message": "Bad Request",
  "error": {
    "field": "price",
    "reason": "Price must be at least 0.01"
  }
}
```

### 401 未認證

API 密鑰缺失或被拒絕時返回。認證入口不保證返回 JSON 回應本體。應用層未認證錯誤若返回 JSON，其 `code` 為 `40101`。

### 404 未找到

請求的資源不存在時返回。

```json
{
  "code": 40401,
  "message": "Resource not found"
}
```

### 429 請求過多

超過配置的頻率限制時返回。預設值為普通 API 請求**每個 IP 每分鐘 100 次**，`POST /v1/checkouts` 建立收銀台為**每個已認證商戶每分鐘 60 次**。限制可配置，不代表生產環境保證提供的配額。

```json
{
  "code": 42901,
  "message": "Rate limit exceeded. Try again later."
}
```

<Tip>
  在你的整合中實現指數退避策略，以優雅地處理頻率限制。
</Tip>

## 成功回應格式

公開商戶 JSON API 的成功回應包含 `code: 0` 和 `message: "success"`。Epay 相容回應和檔案下載使用各介面規定的格式。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    // 回應資料
  }
}
```

對於分頁介面，`data` 欄位包含 `items` 和 `pagination`：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [...],
    "pagination": {
      "page": 1,
      "size": 20,
      "total": 42,
      "totalPages": 3
    }
  }
}
```
