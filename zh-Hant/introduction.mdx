## 使用 KyrenPay 串接國際收款

KyrenPay 為**中國開發者、AI 應用和 SaaS 團隊**提供國際收款能力。在這裡，你可以從建立支付連結開始，也可以透過支付 API 串接託管收銀台，完成訂單確認、履約與資金對帳。

<Card title="選擇適合你的串接方式" icon="arrow-right" href="/zh-Hant/start-here">
  從控制台支付連結到伺服器端 Checkout 整合，按你的產品形態找到串接路徑。
</Card>

## 從建立 Checkout 到確認訂單

<Steps>
  <Step title="準備商戶帳戶">
    完成串接前的帳戶準備，確認可用的[支付方式](/zh-Hant/dashboard/payment-methods)和 [API 憑證](/zh-Hant/authentication)。
  </Step>
  <Step title="建立產品與 Checkout Session">
    設定產品、價格和幣種。在伺服器端建立會話，再將客戶引導至返回的 Checkout 位址。
  </Step>
  <Step title="配置並驗證 Webhook">
    在第一筆付款前配置通知位址。使用原始請求體驗證簽名，並處理可能重複到達的事件。
  </Step>
  <Step title="確認支付並履約">
    根據已驗證的支付事件與訂單記錄更新你的系統，不能僅憑瀏覽器跳轉認定支付成功。
  </Step>
</Steps>

完整實作請參考[收取第一筆款項](/zh-Hant/guides/collect-first-payment)和[上線檢查清單](/zh-Hant/go-live-checklist)。

## 支付方式與可用範圍

可用支付方式、幣種和限額取決於商戶帳戶、已綁定渠道和平台配置。串接時請查看[支付方式](/zh-Hant/dashboard/payment-methods)與[支援幣種 API](/api-reference/config/get-supported-currencies)。費用與結算條件以商戶協議及實際約定為準。
