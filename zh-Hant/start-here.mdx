## 建議路徑

1. 建立或檢查商戶帳戶。
2. 建立一個產品。
3. 建立 Checkout Session 或 Checkout 連結。
4. 完成一次付款流程。
5. 設定並驗證 Webhook。
6. 確認你的系統能正確履約。
7. 檢查上線清單。
