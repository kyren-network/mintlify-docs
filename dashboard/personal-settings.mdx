Use Personal settings to manage your own dashboard account and security settings.

## Common tasks

| Task | Notes |
| --- | --- |

| Password | Use a strong password and update it when team access changes. |
| Two-factor authentication | Enable 2FA to protect sensitive actions. |
| Account security | Review settings before regenerating API keys or changing settlement account information. |

## Set up 2FA

Use two-factor authentication (2FA) to add a one-time verification code requirement to your dashboard account.

1. Sign in to the Kyren Pay merchant dashboard.
2. Open **Personal settings** from the dashboard navigation.
3. Find **Two-factor authentication** and choose **Enable 2FA**.
4. Scan the QR code with an authenticator app such as Google Authenticator, Microsoft Authenticator, or 1Password.
5. Enter the 6-digit code from the authenticator app to confirm setup.
6. Save any recovery codes shown on the page in a secure place.

After 2FA is enabled, keep your authenticator app available when signing in or performing sensitive account actions. If you lose access to the authenticator app or recovery codes, contact Kyren support from a verified account channel.

## Security reminders

- Do not share your password or 2FA codes.
- Do not send API keys, Webhook secrets, or identity documents through chat or email unless Kyren Pay explicitly requests a secure channel.
- Remove access for team members who no longer need the dashboard.
