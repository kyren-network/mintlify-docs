Use the merchant dashboard to manage products, orders, funds, KYC, KYB, developer settings, and personal settings.

## Main areas

| Area | Use it for |
| --- | --- |
| Products | Create and manage what you sell. |
| Orders | Review payments, order status, and reconciliation details. |
| Funds | Review balances, transactions, settlements, and settlement accounts. |
| KYC | Submit and review personal verification information. |
| KYB | Submit and review business verification information. |
| Developer | Manage API keys, Webhook settings, and integration configuration. |
| Personal settings | Manage profile details, account security, password, and 2FA. |

## Recommended first setup

1. Review merchant profile and website information.
2. Create a product.
3. Create a checkout session from the API or generate a checkout flow.
4. Configure Webhooks in Developer settings.
5. Review paid orders in Orders.
