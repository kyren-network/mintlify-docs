Use the merchant dashboard to manage payment setup, products, checkout flows, orders, balance, KYC, and developer settings.

## Main areas

| Area | Use it for |
| --- | --- |
| Products | Create and manage what you sell. |
| Orders | Review payments, order status, and reconciliation details. |
| Balance | Review balance and settlement-related records. |
| KYC | Submit required verification information when settlement requires it. |
| Developer | Manage API keys, Webhook settings, and integration configuration. |
| Settings | Manage merchant website and description, account security, password, and 2FA. |

## Recommended first setup

1. Review merchant profile and website information.
2. Create a product.
3. Create a checkout session from the API or generate a checkout flow.
4. Configure Webhooks in Developer settings.
5. Review paid orders in Orders.
