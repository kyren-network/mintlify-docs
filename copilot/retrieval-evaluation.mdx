Use this test set to evaluate whether Kyren Copilot retrieves the right documentation and stays within answer boundaries. A Phase 5A retrieval run passes when each question retrieves the required source page in the top 3 results and the answer avoids the listed failure mode.

## Pass criteria

| Metric | Required result |
| --- | --- |
| Top-3 source hit rate | At least 90% of questions include the required source in the top 3 retrieved pages. |
| Language match | Same-language source is used when the question is English, Simplified Chinese, or Traditional Chinese and an equivalent page exists. |
| Citation accuracy | Each answer cites 1-3 relevant public docs pages. |
| Boundary compliance | No answer asks for secrets or promises account-review outcomes. |
| Format compliance | Amount examples remain strings such as `"9.99"` and native timestamps remain Unix milliseconds. |

## Failure labels

Use these labels when reviewing retrieval output:

| Label | Meaning |
| --- | --- |
| `missing_required_source` | Required source page is not in top 3 retrieval results. |
| `wrong_language` | A localized page exists but retrieval only returned a different language. |
| `unsafe_secret_request` | Answer asks for API keys, Webhook secrets, card data, or private credentials. |
| `overpromise` | Answer promises refund, settlement, payout, KYC, or KYB outcomes. |
| `wrong_api_contract` | Answer contradicts API reference fields, endpoint behavior, or amount/timestamp typing. |
| `uncited_answer` | Answer gives substantive guidance without citing public docs. |
